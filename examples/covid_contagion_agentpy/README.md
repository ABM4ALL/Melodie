# covid_contagion_agentpy

This is the AgentPy comparison example corresponding to the Melodie COVID contagion model. It is intended for comparing modeling structure and outputs across frameworks.

Dependencies:

- `agentpy`

Run from the repository root:

```bash
python -m examples.covid_contagion_agentpy.main
```

Outputs are written to `examples/covid_contagion_agentpy/data/output/`.
