# covid_contagion_network_visual

This example adds visualization to the network-based contagion model. It provides both a backend simulator entry point and a MelodieStudio entry point.

Run the simulator backend from the repository root:

```bash
python -m examples.covid_contagion_network_visual.run_simulator
```

Run MelodieStudio from the repository root:

```bash
python -m examples.covid_contagion_network_visual.run_studio
```

The browser UI is provided by MelodieStudio. Outputs are written to `examples/covid_contagion_network_visual/data/output/`.
